# 관리자 속성 카테고리 관리 기능

## 설명

- 관리자가 메뉴 특성과 사용자 취향이 공유하는 `attribute category` 기준 데이터를 관리하는 기능이다.
- 속성 카테고리는 맛, 조리 방식, 음식 종류, 식감, 온도감 같은 분류에 사용된다.
- 공개 취향 선택 옵션과 메뉴 추천 알고리즘 입력에 영향을 준다.

## 수용 기준

- 관리자는 활성/비활성 속성 카테고리 목록을 조회할 수 있다.
- 관리자는 새 속성 카테고리를 생성할 수 있다.
- 관리자는 속성 카테고리의 이름, 정렬 순서, 활성 여부를 수정할 수 있다.
- 관리자는 속성 카테고리를 비활성화할 수 있다.
- 중복 `(categoryType, code)`는 생성할 수 없다.
- 일반 회원은 관리자 API를 사용할 수 없다.

## 엣지케이스

- 비관리자 회원이 접근한다.
- 중복 코드로 생성한다.
- 지원하지 않는 `categoryType`으로 생성한다.
- 이미 메뉴나 회원 취향에 연결된 카테고리를 비활성화한다.
- 비활성화된 카테고리를 다시 활성화한다.

## 참고

- 관련 API
  - `GET /api/v1/admin/attribute-categories`
  - `POST /api/v1/admin/attribute-categories`
  - `PATCH /api/v1/admin/attribute-categories/{attributeCategoryId}`
  - `DELETE /api/v1/admin/attribute-categories/{attributeCategoryId}`
- 관련 데이터
  - `attribute_categories`
  - `menu_attribute_categories`
  - `member_taste_profile_categories`
- 미정 사항: 연결된 데이터가 있을 때 비활성화 경고 방식, 정렬 순서 자동 보정, 관리자 화면 제공 범위
