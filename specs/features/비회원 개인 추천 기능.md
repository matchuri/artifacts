# 비회원 개인 추천 기능

## 설명

- 로그인하지 않은 사용자가 일회성 취향 입력으로 메뉴 후보를 추천받는 기능이다.
- 비회원 추천은 추천 이력을 저장하지 않고, 요청에 포함된 취향 조건으로 후보만 반환한다.
- 회원가입 전 서비스 가치를 빠르게 경험하게 하는 진입 기능이다.

## 수용 기준

- 비회원 사용자는 취향 속성, 제한 재료, 비선호 메뉴를 입력해 추천을 요청할 수 있다.
- 요청값이 비어 있으면 빈 목록 기준으로 처리할 수 있다.
- 추천 결과는 후보 메뉴 목록과 순위, 점수를 포함한다.
- 제한 재료와 비선호 메뉴는 후보 제외 조건으로 반영된다.
- 중복 ID, 존재하지 않는 ID, 비활성 ID가 포함되면 실패한다.
- 추천 이력과 후보 선택 로그는 저장하지 않는다.

## 엣지케이스

- 입력한 조건에 맞는 후보가 없다.
- 제한 재료와 비선호 메뉴가 후보를 모두 제외한다.
- 중복된 취향/재료/메뉴 ID가 포함된다.
- 비활성 참조 데이터 ID가 포함된다.
- 추천 알고리즘이 실패한다.

## 참고

- 관련 API: `POST /api/v1/guest/recommendations`
- 관련 데이터: `menu_items`, `menu_attribute_categories`, `menu_ingredients`, `attribute_categories`, `ingredients`
- 미정 사항: 비회원 추천 후 회원가입 유도 방식, 추천 결과 저장 전환 여부, 비회원 추천 입력 UX
