# 인증 및 온보딩 라우팅 가드 기능

## 설명

- 사용자의 인증 상태와 온보딩 완료 상태에 따라 접근 가능한 화면을 제어하는 기능이다.
- 로그인하지 않은 사용자는 보호 화면 대신 로그인 또는 공개 화면으로 이동한다.
- 필수 약관과 닉네임 온보딩이 끝나지 않은 사용자는 필요한 온보딩 화면으로 이동한다.

## 수용 기준

- 인증이 필요한 화면은 로그인하지 않은 사용자의 접근을 막는다.
- 로그인한 사용자는 온보딩 상태에 따라 약관, 닉네임, 홈 화면 중 적절한 위치로 이동한다.
- 필수 약관 미완료 사용자는 핵심 기능 화면에 머무를 수 없다.
- 닉네임 미완료 사용자는 닉네임 설정 화면으로 이동한다.
- 온보딩 완료 사용자는 홈 또는 요청한 보호 화면으로 진입할 수 있다.

## 엣지케이스

- 앱 초기화 중 인증 상태가 아직 확인되지 않았다.
- refresh token 재발급이 실패한다.
- 약관 완료 후 오래된 access token을 계속 사용한다.
- 사용자가 브라우저 뒤로가기로 온보딩 이전 화면으로 돌아간다.
- 공개 화면과 보호 화면 사이에서 리다이렉트 루프가 발생한다.

## 참고

- 관련 API
  - `POST /api/v1/auth/refresh`
  - `GET /api/v1/member-agreements/required-status`
  - `GET /api/v1/members/me`
- 관련 데이터
  - access token
  - refresh token
  - onboarding 상태
  - auth atom/store
- 미정 사항: 로그인 후 원래 가려던 경로 복귀 여부, 리다이렉트 중 로딩 화면 기준, 토큰 저장 위치 장기 정책
