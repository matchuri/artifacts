# 개인 추천 결과 및 후보 선택 기능

## 설명

- 사용자가 개인 추천 후보를 확인하고 최종 메뉴를 선택하는 기능이다.
- 후보는 메뉴 이름, 대표 이미지, 순위, 추천 점수를 포함한다.
- 사용자가 후보를 선택하면 추천은 종료되고 선택 로그가 저장된다.

## 수용 기준

- 사용자는 열린 개인 추천의 상세와 후보 목록을 조회할 수 있다.
- 후보 목록은 추천 순위 기준으로 표시된다.
- 사용자는 후보 중 하나를 최종 선택할 수 있다.
- 선택 성공 시 추천 상태는 `SELECTED`로 종료된다.
- 선택한 메뉴는 사용자 행동 로그로 저장된다.
- 이미 종료되었거나 만료된 추천은 선택할 수 없다.

## 엣지케이스

- 존재하지 않는 추천 ID를 조회한다.
- 다른 사용자의 추천을 조회한다.
- 추천이 이미 선택되었거나 재요청으로 종료되었다.
- 추천이 시간상 만료되었다.
- 후보 목록이 비어 있다.
- 메뉴 대표 이미지가 없다.

## 참고

- 관련 API
  - `GET /api/v1/personal/recommendations/{requestId}`
  - `GET /api/v1/personal/recommendations/{requestId}/candidates`
  - `PATCH /api/v1/personal/recommendations/{requestId}`
- 관련 데이터
  - `personal_recommendations`
  - `personal_recommendation_candidates`
  - `member_menu_actions`, `menu_items`
  - `menu_item_images`
- 미정 사항: 후보 카드에 보여줄 추천 이유, 선택 후 식당 탐색 연결 방식, 만료된 결과 화면 처리
