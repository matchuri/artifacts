# 관리자 메뉴 관리 기능

## 설명

- 관리자가 추천 가능한 메뉴의 기본 정보를 생성, 조회, 수정, 비활성화하는 기능이다.
- 메뉴는 개인 추천, 그룹 추천, 비선호 메뉴 선택, 식당 탐색 연결의 기본 단위다.
- 메뉴 비활성화는 공개 메뉴 조회와 추천 후보 생성에 영향을 준다.

## 수용 기준

- 관리자는 활성/비활성 메뉴 목록을 조회할 수 있다.
- 관리자는 메뉴 상세를 조회할 수 있다.
- 관리자는 새 메뉴를 생성할 수 있다.
- 관리자는 메뉴 이름, 설명, 활성 여부를 수정할 수 있다.
- 관리자는 메뉴를 비활성화할 수 있다.
- 중복 메뉴 `code`는 생성할 수 없다.

## 엣지케이스

- 비관리자 회원이 접근한다.
- 중복 코드로 메뉴를 생성한다.
- 이름이나 설명 길이가 정책을 초과한다.
- 추천 후보나 비선호 메뉴에 이미 사용된 메뉴를 비활성화한다.
- 비활성 메뉴를 공개 메뉴 검색이나 취향 저장에 사용한다.

## 참고

- 관련 API: `GET /api/v1/admin/menu-items`, `GET /api/v1/admin/menu-items/{menuItemId}`, `POST /api/v1/admin/menu-items`, `PATCH /api/v1/admin/menu-items/{menuItemId}`, `DELETE /api/v1/admin/menu-items/{menuItemId}`
- 관련 데이터: `menu_items`, `personal_recommendation_candidates`, `group_recommendation_candidates`, `member_taste_profile_disliked_menu_items`
- 미정 사항: 메뉴 코드 생성 규칙, 비활성 메뉴의 과거 추천 노출 방식, 메뉴 삭제 대신 비활성화만 유지할지 여부
