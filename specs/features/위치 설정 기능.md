# 위치 설정 기능

## 설명

- 사용자가 추천 이후 주변 식당 탐색이나 그룹 위치 판단에 사용할 위치를 설정하는 기능이다.
- 위치는 현재 위치, 지도 선택, 주소 검색 등의 방식으로 정할 수 있다.
- 위치 설정은 메뉴 결정 이후의 장소 탐색을 돕는 보조 정보다.

## 수용 기준

- 사용자는 위치 설정 UI를 열 수 있다.
- 사용자는 현재 위치 또는 검색한 위치를 선택할 수 있다.
- 선택한 위치는 이후 식당 탐색 또는 그룹 위치 입력에 사용할 수 있다.
- 위치 권한이 없으면 수동 검색 또는 기본 위치를 사용할 수 있다.
- 위치 정보 저장/불러오기는 사용자 흐름을 방해하지 않아야 한다.

## 엣지케이스

- 브라우저 위치 권한이 거부된다.
- 위치 검색 결과가 없다.
- 지도 SDK 또는 지오코딩이 실패한다.
- 저장된 위치가 오래되었거나 현재 사용 맥락과 맞지 않는다.
- 모바일에서 지도 조작이 입력 UI와 충돌한다.
