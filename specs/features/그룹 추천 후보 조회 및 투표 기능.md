# 그룹 추천 후보 조회 및 투표 기능

## 설명

- 그룹원이 그룹 추천 후보 메뉴를 확인하고 하나의 후보에 투표하는 기능이다.
- 후보는 그룹 구성원의 취향을 반영해 최대 3개 제시한다.
- 그룹원은 추천 세션 상세에서 이번 후보를 설명하는 카테고리를 확인한다. 카테고리는 당시 그룹원의 공통 취향(`COMMON`)을 우선하고 부족하면 후보 메뉴의 카테고리(`MENU`)로 채운다.
- 투표 현황은 그룹 합의가 어디까지 진행되었는지 보여준다.

## 수용 기준

- 현재 활성 그룹 멤버는 추천 세션 상세를 조회할 수 있고, 열린 추천 세션의 후보 목록을 조회할 수 있다.
- 준비 중인 세션의 상세에는 후보가 빈 배열이고 `recommendationCategories`는 `null`이다. 별도 후보 목록 조회와 투표는 허용하지 않는다.
- 모든 현재 활성 그룹원이 준비 완료해 후보가 생성될 때, 동일한 시점의 멤버 취향과 후보 메뉴에서 카테고리를 한 번 선택해 추천 세션에 저장한다.
- `COMMON`은 당시 모든 활성 그룹원이 선호하고 실제 추천 후보에도 연결된 활성 속성 카테고리다. 후보에 연결된 횟수가 많은 순서로 최대 5개를 선택하며, 동률이면 `categoryType`, `sortOrder`, ID 순서다.
- 공통 카테고리가 5개 미만이면 후보의 `rankNo` 순서로 활성 메뉴 카테고리를 보충한다. 같은 후보 안에서는 `categoryType`, `sortOrder`, ID 순서이며 이미 선택한 카테고리는 중복하지 않는다. 보충한 항목의 `source`는 `MENU`다.
- 후보 생성 후 세션 상세의 `recommendationCategories`는 `id`, `categoryType`, `code`, `name`, `rankNo`, `source`를 표시 순서대로 최대 5개 반환한다. 가능한 카테고리가 부족하면 5개 미만이며, 없으면 빈 배열이다.
- 저장된 카테고리 ID·출처·순위는 이후 취향 수정이나 그룹 탈퇴로 바뀌지 않는다. 카테고리 이름은 별도 저장하지 않고 조회 당시의 현재 이름을 반환한다.
- 그룹 상세의 `recentlyRecommendation`에는 `recommendationCategories`를 제공하지 않는다.
- 그룹 멤버는 후보 중 하나에 투표할 수 있다.
- 한 사용자는 같은 추천 세션에 한 표를 가진다. 다시 투표하면 선택 후보를 변경하고, 같은 후보에 다시 투표해도 표가 늘어나지 않는다.
- 후보별 투표 수와 투표 진행률을 확인할 수 있다.
- 추천 상세에는 현재 활성 그룹원의 회원별 투표 여부와 선택 후보가 표시된다.
- 투표 상태 변화는 그룹 실시간 이벤트로 전달된다.

## 엣지케이스

- 준비 중인 세션에 투표한다.
- 존재하지 않는 후보에 투표한다.
- 한 그룹원의 취향 프로필이 없어서 공통 카테고리가 없거나, 후보에 연결된 카테고리가 없어 빈 배열을 반환한다.
- 그룹원 모두가 선호한 카테고리가 후보에는 연결되지 않아 `COMMON`에서 제외된다.
- 여러 후보에 같은 카테고리가 연결되어 있어도 한 번만 표시한다.
- 후보 생성 후 그룹원이 취향을 수정하거나 탈퇴하고, 카테고리 이름이 바뀌거나 비활성화된다.
- 같은 사용자가 같은 후보 또는 다른 후보에 다시 투표한다.
- 그룹 멤버가 아닌 사용자가 투표한다.
- 투표 중 세션이 최종 확정된다.
- 후보 메뉴가 비활성화되거나 이미지가 없다.
