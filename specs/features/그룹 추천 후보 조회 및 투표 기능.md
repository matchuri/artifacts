# 그룹 추천 후보 조회 및 투표 기능

## 설명

- 그룹원이 그룹 추천 후보 메뉴를 확인하고 하나의 후보에 투표하는 기능이다.
- 후보는 그룹 구성원의 취향을 반영해 3개 안팎으로 제시한다.
- 투표 현황은 그룹 합의가 어디까지 진행되었는지 보여준다.

## 수용 기준

- 그룹 멤버는 열린 추천 세션의 후보 목록을 조회할 수 있다.
- 준비 중인 추천 세션에서는 후보 목록 조회가 실패하거나 준비 상태로 안내된다.
- 그룹 멤버는 후보 중 하나에 투표할 수 있다.
- 한 사용자는 같은 추천 세션에 중복 투표할 수 없다.
- 후보별 투표 수와 투표 진행률을 확인할 수 있다.
- 투표 상태 변화는 그룹 실시간 이벤트로 반영될 수 있다.

## 엣지케이스

- 준비 중인 세션에 투표한다.
- 존재하지 않는 후보에 투표한다.
- 같은 사용자가 중복 투표한다.
- 그룹 멤버가 아닌 사용자가 투표한다.
- 투표 중 세션이 최종 확정된다.
- 후보 메뉴가 비활성화되거나 이미지가 없다.

## 참고

- 관련 API
  - `GET /api/v1/groups/{groupId}/recommendations/{sessionId}`
  - `GET /api/v1/groups/{groupId}/recommendations/{sessionId}/candidates`
  - `POST /api/v1/groups/{groupId}/recommendations/{sessionId}/votes`
  - `GET /api/v1/groups/{groupId}/realtime/events`
- 관련 데이터
  - `group_recommendations`
  - `group_recommendation_candidates`
  - `group_recommendation_votes`
  - `group_members`
  - `menu_items`
- 미정 사항: 투표 변경 허용 여부, 익명 투표 여부, 후보 수 고정 여부
