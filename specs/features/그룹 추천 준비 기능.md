# 그룹 추천 준비 기능

## 설명

- 그룹 `OWNER`가 그룹 추천 세션을 시작하고, 각 그룹원이 취향을 확인한 뒤 준비 완료하는 기능이다.
- 전원이 준비 완료되면 시스템은 그룹 취향을 반영해 후보 메뉴를 생성한다.
- 이 단계는 그룹원이 각자의 취향을 반영할 마지막 기회다.

## 수용 기준

- `OWNER`는 그룹 추천 준비 세션을 시작할 수 있다.
- 그룹 멤버는 준비 상태를 조회할 수 있다.
- 각 그룹원은 자신의 취향을 확인하거나 수정한 뒤 준비 완료할 수 있다.
- 전원 준비 완료 시 후보 메뉴가 생성되고 추천 상태가 열린다.
- 준비 중에는 후보 목록 투표가 아직 불가능하다.
- 그룹 멤버가 아니면 준비 상태를 조회하거나 완료할 수 없다.

## 엣지케이스

- 일반 멤버가 추천 세션을 시작한다.
- 이미 진행 중인 추천 세션이 있다.
- 취향 프로필이 없는 멤버가 준비 완료한다.
- 준비 완료 직전 멤버가 탈퇴한다.
- 전원 준비 완료 후 후보 생성이 실패한다.
- 그룹이 삭제된 상태에서 준비 API를 호출한다.

## 참고

- 관련 API
  - `POST /api/v1/groups/{groupId}/recommendations`
  - `GET /api/v1/groups/{groupId}/recommendations/{sessionId}/readiness`
  - `POST /api/v1/groups/{groupId}/recommendations/{sessionId}/ready`
  - `GET /api/v1/groups/{groupId}/realtime/events`
- 관련 데이터
  - `group_recommendations`
  - `group_recommendation_readiness`
  - `group_members`
  - `member_taste_profiles`
  - `group_recommendation_candidates`
- 미정 사항: 취향 없는 멤버의 준비 완료 허용 기준, 준비 완료 후 취향 수정 반영 여부, 전원 준비 기준의 활성 멤버 범위
