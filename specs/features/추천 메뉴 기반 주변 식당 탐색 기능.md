# 추천 메뉴 기반 주변 식당 탐색 기능

## 설명

- 사용자가 추천받거나 선택한 메뉴를 기준으로 주변 식당을 탐색하는 보조 기능이다.
- Matchuri의 핵심은 메뉴 결정이며, 식당 탐색은 메뉴 결정 이후의 보조 레이어다.
- 현재 프론트는 위치와 메뉴 키워드를 바탕으로 외부 장소 검색을 사용할 수 있다.

## 수용 기준

- 사용자는 선택한 메뉴 또는 추천 메뉴명을 기준으로 식당 검색을 시작할 수 있다.
- 사용자의 현재 또는 설정 위치가 검색 기준으로 사용된다.
- 검색 결과는 식당명, 주소, 거리, 지도 위치 등 탐색에 필요한 정보를 제공한다.
- 검색 결과가 없으면 빈 상태를 안내한다.
- 메뉴 추천 결과와 장소 검색 결과는 서로 다른 책임으로 분리된다.

## 엣지케이스

- 위치 권한이 없거나 위치 설정이 없다.
- 외부 장소 검색 API가 실패한다.
- 선택한 메뉴명으로 검색 결과가 없다.
- 검색 결과가 너무 멀거나 관련성이 낮다.
- 모바일 환경에서 지도와 목록 표시가 겹친다.
