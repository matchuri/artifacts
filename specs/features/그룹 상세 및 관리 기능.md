# 그룹 상세 및 관리 기능

## 설명

- 사용자가 그룹 상세 정보, 멤버, 초대 코드, 진행 중인 추천 상태를 확인하는 기능이다.
- 그룹 `OWNER`는 그룹 이름과 위치를 수정할 수 있다.
- 그룹 상세는 추천 시작, 초대, 탈퇴/삭제 같은 그룹 작업의 허브 역할을 한다.

## 수용 기준

- 그룹 활성 멤버는 그룹 상세를 조회할 수 있다.
- 그룹 상세에는 그룹 기본 정보, 멤버 목록, 초대 코드, 진행 중 추천 정보가 표시된다.
- `OWNER`는 그룹 이름을 수정할 수 있다.
- `OWNER`는 그룹 위치를 수정할 수 있다.
- 일반 멤버는 그룹 정보를 수정할 수 없다.
- 그룹이 삭제되었거나 멤버가 아니면 상세에 접근할 수 없다.

## 엣지케이스

- 존재하지 않는 그룹을 조회한다.
- 그룹 멤버가 아닌 사용자가 접근한다.
- 일반 멤버가 이름 또는 위치를 수정한다.
- 그룹 삭제 직후 상세 화면에 남아 있다.
- 위치 수정 중 외부 지도/주소 검색이 실패한다.

## 참고

- 관련 API
  - `GET /api/v1/groups/{groupId}`
  - `PATCH /api/v1/groups/{groupId}`
- 관련 데이터
  - `group_rooms`
  - `group_members`
  - `group_invites`
  - `group_recommendations`
- 미정 사항: 그룹 위치 필드의 정확한 형식, 멤버 역할 추가 여부, 그룹 상세에서 보여줄 추천 요약 범위
