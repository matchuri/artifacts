# 개인 추천 재요청 기능

## 설명

- 사용자가 기존 개인 추천이 마음에 들지 않거나 취향 입력을 바꾼 뒤 새 후보를 받는 기능이다.
- 재요청은 기존 추천을 종료하고 새 추천 실행 단위를 만든다.
- 재요청 사유에 따라 기존 후보를 잠시 제외할지 여부가 달라진다.

## 수용 기준

- 사용자는 열린 개인 추천에 대해 재요청할 수 있다.
- `NOT_SATISFIED` 재요청은 기존 후보에 `SKIP` 로그를 남긴다.
- `INPUT_CHANGED` 재요청은 기존 후보에 `SKIP` 로그를 남기지 않는다.
- 재요청 성공 시 기존 추천은 종료되고 새 추천이 생성된다.
- 이미 종료되었거나 만료된 추천은 재요청할 수 없다.
- `SKIP` 로그가 남은 메뉴는 일정 시간 후보에서 제외된다.

## 엣지케이스

- 종료된 추천을 재요청한다.
- 만료된 추천을 재요청한다.
- 잘못된 `rerollType`을 보낸다.
- 재요청 후 새 후보가 부족하다.
- 취향 변경 저장은 성공했지만 재요청은 실패한다.
- 여러 번 빠르게 재요청 버튼을 누른다.

## 참고

- 관련 API
  - `POST /api/v1/personal/recommendations/{requestId}/reroll`
  - `PATCH /api/v1/members/me/taste-profile`
- 관련 데이터
  - `personal_recommendations`
  - `personal_recommendation_candidates`
  - `member_menu_actions`
  - `member_taste_profiles`
- 미정 사항: 재요청 버튼 노출 횟수 제한, `SKIP` 제외 기간 사용자 안내, 취향 변경 후 자동 재추천 여부
