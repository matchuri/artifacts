# 내 기본 정보 관리 기능

## 설명

- 사용자가 자신의 기본 프로필 정보를 조회하고 수정하는 기능이다.
- 기본 프로필에는 회원 ID, 로그인 ID, 닉네임, 소셜 로그인 여부, 이메일이 포함된다.
- 현재 수정 대상은 닉네임 중심이며, 취향 프로필은 별도 기능으로 관리한다.

## 수용 기준

- 로그인한 사용자는 내 기본 정보를 조회할 수 있다.
- 사용자는 닉네임을 수정할 수 있다.
- 닉네임 수정 성공 시 최신 수정 시각과 온보딩 상태가 반환된다.
- 중복 닉네임은 저장할 수 없다.
- 소셜 로그인 회원은 로그인 ID가 없을 수 있다.
- 취향 프로필 상세는 내 기본 정보 응답에 포함되지 않는다.

## 엣지케이스

- 인증이 없거나 만료된 사용자가 조회한다.
- 중복 닉네임으로 수정한다.
- 닉네임 형식이 잘못되었다.
- 닉네임 중복 확인 후 저장 전 다른 사용자가 선점한다.
- 탈퇴 또는 비활성 회원이 접근한다.

## 참고

- 관련 API: `GET /api/v1/members/me`, `PATCH /api/v1/members/me`, `GET /api/v1/members/exists/nickname/{nickname}`
- 관련 데이터: `members`
- 미정 사항: 이메일 수정 지원 여부, 닉네임 변경 횟수 제한, 프로필 이미지 도입 여부
