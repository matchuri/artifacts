# 개인 추천 이력 조회 기능

## 설명

- 로그인한 사용자가 과거에 최종 메뉴를 선택한 개인 추천 이력을 최신순으로 조회하는 기능이다.
- 현재 이력 화면이 사용하는 v2 API는 `SELECTED` 상태만 제공한다. 진행 중이거나 재요청·만료·실패로 종료된 추천은 이 목록에 포함하지 않는다.
- 각 이력은 추천 실행·종료 시각과 최종 선택 메뉴의 점수, 이름, 활성 태그, 대표 이미지를 제공한다.
- 진행 중 추천을 이어가는 흐름은 홈의 최신 개인 추천 정보와 추천 상세 조회가 담당한다.

## 정량 제약사항

- `page`는 0부터 시작하며 기본값은 0, 허용 최솟값은 0이다.
- `size` 기본값은 20이며 1~100 범위만 허용한다.
- 이력은 `requestedAt` 내림차순으로 정렬하고, 요청 시각이 같으면 추천 ID 내림차순으로 정렬한다.
- 이력 보관 기간과 사용자가 조회할 수 있는 전체 건수에는 현재 별도 제한이 정해져 있지 않다.

## 수용 기준

- 로그인한 사용자는 자신의 `SELECTED` 개인 추천 이력만 조회할 수 있다.
- 응답은 `content`와 `pageInfo`를 포함하며 `pageInfo`에는 현재 페이지, 페이지 크기, 전체 건수, 전체 페이지 수, 첫·마지막 페이지 여부, 이전·다음 페이지 여부가 포함된다.
- 각 이력에는 `id`, `status`, `requestedAt`, `closedAt`, `score`, `menuName`, `tags`, `thumbnailUrl`이 포함된다.
- 대표 메뉴는 해당 추천에서 최종 선택한 후보이며, 점수는 추천 당시 후보에 저장된 0~100 정규화 점수다.
- 메뉴명, 활성 속성 태그, 대표 이미지는 조회 시점의 현재 메뉴 데이터를 사용한다. 대표 이미지가 없으면 `thumbnailUrl`은 `null`, 활성 태그가 없으면 `tags`는 빈 목록이다.
- 이력 항목을 선택하면 해당 추천의 상세 결과로 이동할 수 있다.
- 이력 조회 전에 24시간이 지난 미선택 `OPEN` 추천은 `EXPIRED`로 정리되지만 v2 이력 목록에는 포함되지 않는다.
- 요청한 페이지에 데이터가 없으면 빈 `content`와 유효한 `pageInfo`를 반환한다.

## 엣지케이스

- 최종 선택한 추천 이력이 없다.
- 전체 페이지 범위를 넘는 페이지를 요청한다.
- 음수 `page`, 0 이하 또는 100 초과 `size`를 요청한다.
- 선택 당시와 조회 시점 사이에 메뉴명, 태그, 대표 이미지가 변경되거나 대표 이미지가 제거되었다.
- 이력에서 상세로 이동하는 사이 추천이 삭제되었거나 소유권 확인에 실패한다.
- 네트워크 실패로 목록을 불러오지 못한다.
- 기본 조회 결과 20건보다 많은 이력이 있지만 다음 페이지를 아직 불러오지 않았다.

## 참고

- 관련 API
  - `GET /api/v2/personal/recommendations`
  - `GET /api/v1/personal/recommendations/{requestId}`
  - `GET /api/v1/personal/recommendations` (`deprecated`, 전체 상태 요약 목록)
- 관련 데이터
  - `personal_recommendations`
  - `personal_recommendation_candidates`
  - `menu_items`, `menu_item_images`, `menu_attribute_categories`
- 미정 사항:
  - 이력 보관 기간과 삭제·숨김 지원 여부
  - 20건을 초과하는 이력의 더 보기, 무한 스크롤 또는 페이지 이동 UX
  - 추천 당시 메뉴명·태그·이미지를 스냅샷으로 보존할지 여부
