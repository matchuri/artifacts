# 개인 추천 이력 조회 기능

## 설명

- 사용자가 자신의 과거 개인 추천 실행 이력을 조회하는 기능이다.
- 이력은 추천 상태, 요청 시각, 종료 시각, 선택 결과를 확인하는 데 사용된다.
- 열린 추천이 있으면 사용자는 이어서 결과 확인 또는 선택을 할 수 있다.

## 수용 기준

- 로그인한 사용자는 자신의 개인 추천 이력 목록을 조회할 수 있다.
- 이력 목록은 페이지네이션을 지원한다.
- 목록에는 추천 상태와 주요 시각 정보가 포함된다.
- 시간상 만료된 열린 추천은 조회 시 만료 상태로 정리된다.
- 사용자는 이력에서 특정 추천 상세로 이동할 수 있다.
- 다른 사용자의 추천 이력은 조회할 수 없다.

## 엣지케이스

- 추천 이력이 없다.
- 페이지 번호나 크기가 잘못되었다.
- 열린 추천이 조회 시점에 만료 대상이다.
- 상세 이동 시 추천이 이미 삭제되었거나 접근 불가하다.
- 네트워크 실패로 목록을 불러오지 못한다.

## 참고

- 관련 API
  - `GET /api/v1/personal/recommendations`
  - `GET /api/v1/personal/recommendations/{requestId}`
- 관련 데이터
  - `personal_recommendations`
  - `personal_recommendation_candidates`
  - `member_menu_actions`
- 미정 사항: 이력 보관 기간, 이력 삭제/숨김 지원 여부, 목록에서 후보까지 미리 보여줄지 여부
