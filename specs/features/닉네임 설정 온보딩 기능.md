# 닉네임 설정 온보딩 기능

## 설명

- 신규 회원 또는 닉네임 미완료 회원이 서비스에서 사용할 닉네임을 확정하는 기능이다.
- 소셜 로그인 회원은 임시 닉네임이 있을 수 있으나, 핵심 기능 사용 전 최종 닉네임 설정이 필요하다.
- 닉네임 완료 여부는 온보딩 완료 상태의 일부다.

## 수용 기준

- 사용자는 닉네임 중복 여부를 확인할 수 있다.
- 사용자는 사용 가능한 닉네임으로 내 기본 정보를 수정할 수 있다.
- 닉네임 수정 성공 시 닉네임 온보딩이 완료된다.
- 필수 약관 완료 후 닉네임 미완료 상태이면 닉네임 설정 화면으로 이동한다.
- 중복 닉네임이나 형식이 잘못된 닉네임은 저장할 수 없다.

## 엣지케이스

- 중복 닉네임을 제출한다.
- 공백만 있는 닉네임을 제출한다.
- 닉네임 최대 길이를 초과한다.
- 중복 확인 후 다른 사용자가 먼저 같은 닉네임을 선점한다.
- 필수 약관 미완료 상태에서 닉네임 설정을 시도한다.

## 참고

- 관련 API
  - `GET /api/v1/members/exists/nickname/{nickname}`
  - `PATCH /api/v1/members/me`
- 관련 데이터
  - `members`
- 미정 사항: 닉네임 허용 문자 정책, 임시 닉네임 노출 여부, 닉네임 변경 횟수 제한
