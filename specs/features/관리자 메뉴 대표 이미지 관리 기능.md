# 관리자 메뉴 대표 이미지 관리 기능

## 설명

- 관리자가 메뉴 대표 이미지를 업로드하거나 삭제하는 기능이다.
- 대표 이미지는 추천 후보, 메뉴 상세, 결과 화면에서 메뉴 인지를 돕는다.
- 이미지 파일은 서버 검증 후 외부 스토리지에 저장하고 메뉴와 연결한다.

## 수용 기준

- 관리자는 메뉴 대표 이미지를 업로드할 수 있다.
- 업로드 파일은 지원 MIME type, 파일 크기, 해상도 기준을 통과해야 한다.
- 대표 이미지가 이미 있으면 새 이미지로 교체된다.
- 관리자는 메뉴 대표 이미지를 삭제할 수 있다.
- 대표 이미지가 없는 메뉴도 정상적으로 조회된다.
- 일반 회원은 이미지 관리 API를 사용할 수 없다.

## 엣지케이스

- 빈 파일을 업로드한다.
- 지원하지 않는 MIME type을 업로드한다.
- 파일 크기 또는 해상도 제한을 초과한다.
- 실제 이미지로 디코딩되지 않는 파일을 업로드한다.
- 스토리지 업로드는 성공했지만 DB 저장이 실패한다.
- 대표 이미지 삭제 요청 시 이미 이미지가 없다.

## 참고

- 관련 API
  - `POST /api/v1/admin/menu-items/{menuItemId}/images`
  - `DELETE /api/v1/admin/menu-items/{menuItemId}/images/primary`
- 관련 데이터
  - `image_assets`
  - `menu_item_images`
  - `menu_items`
- 미정 사항: 썸네일 별도 생성 여부, 이미지 교체 시 기존 객체 삭제 보장 수준, 기본 이미지 제공 여부
