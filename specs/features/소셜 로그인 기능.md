# 소셜 로그인 기능

## 설명

- 사용자가 Google, Kakao, Naver 같은 외부 OAuth2 provider로 로그인하거나 가입하는 기능이다.
- 소셜 로그인 성공 후 서버는 provider 계정 정보를 바탕으로 회원을 찾거나 새 회원을 생성한다.
- 신규 소셜 회원은 필수 약관과 닉네임 온보딩을 완료해야 핵심 기능을 사용할 수 있다.
- 프론트는 OAuth2 callback 후 code 교환 결과의 온보딩 상태에 따라 다음 화면으로 이동한다.

## 수용 기준

- 사용자는 지원되는 provider의 로그인 시작 URL로 이동할 수 있다.
- OAuth2 callback code를 서버에 교환해 access token과 refresh token을 받을 수 있다.
- 기존 소셜 회원은 로그인 후 온보딩 상태에 맞는 화면으로 이동한다.
- 신규 소셜 회원은 필수 약관 동의 화면으로 이동한다.
- 필수 약관과 닉네임을 완료하기 전에는 핵심 기능 접근이 차단된다.
- 지원하지 않는 provider나 잘못된 code 교환은 실패한다.

## 엣지케이스

- provider 인증을 사용자가 취소한다.
- callback code가 없거나 만료되었다.
- provider에서 필수 사용자 식별 정보가 내려오지 않는다.
- 이미 다른 방식으로 가입한 이메일과 충돌한다.
- 소셜 로그인 직후 필수 약관 동의가 필요하다.
- 필수 약관 완료 후 닉네임 설정이 필요하다.

## 참고

- 관련 API: `GET /api/v1/auth/oauth2/{provider}`, `POST /api/v1/auth/oauth2/exchange`, `GET /api/v1/member-agreements/required-status`, `POST /api/v1/member-agreements/consents`, `PATCH /api/v1/members/me`
- 관련 데이터: `members`, `member_agreements`, `auth_exchange_codes`, `auth_refresh_tokens`
- 미정 사항: provider별 계정 충돌 처리 문구, 소셜 계정 연결/해제 지원 여부, provider 추가 우선순위
