# 로그인 ID 찾기 기능

## 설명

- 사용자가 가입 이메일 인증을 통해 자신의 로그인 ID를 확인하는 기능이다.
- 계정 복구 흐름 중 비밀번호 재설정과 분리된 기능으로 제공한다.
- 인증된 이메일에 연결된 계정 정보만 노출한다.

## 수용 기준

- 사용자는 이메일 인증을 요청할 수 있다.
- 사용자는 인증 코드를 확인한 뒤 로그인 ID 찾기를 요청할 수 있다.
- 인증 성공 후 해당 이메일에 연결된 로그인 ID가 표시된다.
- 소셜 전용 회원이나 로그인 ID가 없는 계정은 별도 안내가 제공된다.
- 인증되지 않은 요청은 로그인 ID를 반환하지 않는다.

## 엣지케이스

- 가입되지 않은 이메일로 요청한다.
- 인증 코드를 잘못 입력한다.
- 인증이 만료된 뒤 로그인 ID 찾기를 시도한다.
- 소셜 로그인 전용 계정이라 로그인 ID가 없다.
- 같은 이메일에 복수 계정 정책이 존재할 경우 표시 기준이 필요하다.

## 참고

- 관련 API: `POST /api/v1/auth/email`, `POST /api/v1/auth/email/confirm`, `POST /api/v1/auth/recovery/login-id`
- 관련 데이터: `members`, `auth_email_verifications`
- 미정 사항: 소셜 전용 계정 안내 문구, 결과 화면에서 로그인으로 돌아가는 UX, 복수 계정 정책
