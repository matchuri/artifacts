# 초대 코드 기반 그룹 참여 기능

## 설명

- 그룹마다 생성된 고정 초대 코드로 직접 참여할 수 있는 백엔드 기능이다.
- 고정 초대 코드는 데이터와 참여 로직에 유지하지만 실 서비스에서는 사용하지 않는다. 현재 프론트에는 코드 입력 화면이 없다.
- 실 서비스 사용자 초대는 닉네임 초대 또는 UUID 초대 링크를 사용한다. 고정 코드에는 별도 만료 시각이 없고, UUID 링크만 발급 시점부터 1일 뒤 만료된다.

## 수용 기준

- 인증된 활성 회원은 기존 참여 API에 고정 초대 코드를 전달해 그룹 참여를 요청할 수 있다. 사용자 화면의 수용 기준으로는 적용하지 않는다.
- 유효한 초대 코드이면 사용자는 그룹 멤버가 된다.
- 이미 그룹에 속한 사용자는 중복 참여할 수 없다.
- 삭제되었거나 비활성화된 그룹에는 참여할 수 없다.
- 존재하지 않는 코드는 실패한다. 코드 자체의 시간 만료는 없으며 대상 그룹이 비활성이면 참여할 수 없다.

## 엣지케이스

- 초대 코드가 존재하지 않는다.
- 이미 그룹 멤버인 사용자가 다시 참여한다.
- 그룹이 삭제된 상태다.
- 인증이 없는 사용자가 코드를 입력한다.

## 참고

- 관련 API
  - `POST /api/v1/groups/join`
- 관련 데이터
  - `group_room_members`
  - `group_rooms`
- 미정 사항: 고정 코드의 실 서비스 재도입 여부
