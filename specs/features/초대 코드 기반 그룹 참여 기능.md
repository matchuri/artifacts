# 초대 코드 기반 그룹 참여 기능

## 설명

- 사용자가 초대 코드로 그룹에 직접 참여하는 기능이다.
- 닉네임 초대 없이도 공유된 코드로 빠르게 그룹에 들어갈 수 있게 한다.
- 기존 그룹 초대 코드 기반 참여 API를 사용한다.

## 수용 기준

- 로그인한 사용자는 초대 코드를 입력해 그룹 참여를 요청할 수 있다.
- 유효한 초대 코드이면 사용자는 그룹 멤버가 된다.
- 이미 그룹에 속한 사용자는 중복 참여할 수 없다.
- 삭제되었거나 비활성화된 그룹에는 참여할 수 없다.
- 잘못되었거나 만료된 초대 코드는 실패한다.

## 엣지케이스

- 초대 코드가 존재하지 않는다.
- 초대 코드가 만료되었거나 폐기되었다.
- 이미 그룹 멤버인 사용자가 다시 참여한다.
- 그룹이 삭제된 상태다.
- 인증이 없는 사용자가 코드를 입력한다.

## 참고

- 관련 API
  - `POST /api/v1/groups/join`
- 관련 데이터
  - `group_invites`
  - `group_members`
  - `group_rooms`
- 미정 사항: 초대 코드 재발급 기능, 코드 입력 화면 위치, 링크 기반 초대 URL 형식
