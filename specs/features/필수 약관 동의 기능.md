# 필수 약관 동의 기능

## 설명

- 사용자가 서비스 이용에 필요한 필수 약관 최신 버전에 동의하는 기능이다.
- 필수 약관 동의 완료 여부는 핵심 기능 접근 가능 여부를 판단하는 기준이다.
- 현재 필수 약관은 서비스 이용약관과 개인정보 처리방침이다.

## 수용 기준

- 로그인한 사용자는 자신의 필수 약관 완료 상태를 조회할 수 있다.
- 필수 약관 미완료 사용자는 약관 동의 화면으로 이동한다.
- 사용자는 최신 필수 버전의 필수 약관을 모두 제출해야 완료된다.
- 완료 후 새 access token 또는 갱신된 온보딩 상태가 제공된다.
- 필수 약관 미완료 상태에서는 핵심 보호 API가 차단된다.
- 잘못된 약관 종류, 누락된 필수 약관, 버전 불일치는 실패한다.

## 엣지케이스

- 일부 필수 약관만 동의한다.
- 최신 버전이 아닌 약관 버전을 제출한다.
- 지원하지 않는 약관 타입을 제출한다.
- 약관 동의 후 기존 access token으로 핵심 API를 호출한다.
- 약관은 완료했지만 닉네임 온보딩이 남아 있다.

## 참고

- 관련 API
  - `GET /api/v1/member-agreements/required-status`
  - `POST /api/v1/member-agreements/consents`
- 관련 데이터
  - `member_agreements`
  - `members`
- 미정 사항: 약관 전문 표시 위치, 약관 버전 갱신 시 재동의 UX, 선택 약관 도입 여부
