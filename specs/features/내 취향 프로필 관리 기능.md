# 내 취향 프로필 관리 기능

## 설명

- 사용자가 자신의 점심 메뉴 취향을 조회하고 수정하는 기능이다.
- 사용자는 선호하는 맛, 조리 방식, 음식 종류, 식감, 온도를 선택할 수 있다.
- 사용자는 피하고 싶은 재료와 선호하지 않는 메뉴를 검색해 추가하거나 제거할 수 있다.
- 저장된 취향은 개인 추천과 그룹 추천에서 메뉴 후보를 만들 때 사용된다.
- 취향 프로필이 없어도 빈 상태로 진입할 수 있으며, 저장 시 최신 입력값으로 전체 교체된다.

## 수용 기준

- 로그인한 사용자는 내 취향 프로필을 조회할 수 있다.
- 취향 프로필이 없는 사용자는 빈 선택 상태를 볼 수 있다.
- 사용자는 맛과 조리 방식을 각각 하나 이상 선택해야 저장할 수 있다.
- 사용자는 음식 종류, 식감, 온도, 제한 재료, 비선호 메뉴를 선택하지 않아도 저장할 수 있다.
- 사용자는 제한 재료와 비선호 메뉴를 검색해 선택하고 제거할 수 있다.
- 저장 후 다시 조회하면 최신 선택 상태가 유지된다.
- 중복 ID, 존재하지 않는 ID, 비활성 ID가 포함된 저장 요청은 실패한다.
- 취향 수정 시 열린 개인 추천이 있으면 새 취향으로 재추천할 수 있는 진입점을 제공한다.

## 엣지케이스

- 인증이 없거나 만료된 사용자가 접근한다.
- 필수 약관 또는 닉네임 온보딩을 완료하지 않은 사용자가 저장을 시도한다.
- 취향 선택 옵션 조회에 실패한다.
- 기존 취향 프로필 조회에 실패한다.
- 필수 항목을 선택하지 않고 저장한다.
- 변경된 내용이 없는데 저장한다.
- 저장 중 사용자가 저장 버튼을 여러 번 누른다.
- 검색 결과가 없거나 검색 API가 실패한다.
- 저장 직전 선택했던 항목이 비활성화된다.
- 열린 개인 추천 재요청은 실패하지만 취향 저장은 성공한다.

## 참고

- 관련 API
  - `GET /api/v1/members/me/taste-profile`
  - `PATCH /api/v1/members/me/taste-profile`
  - `GET /api/v1/attribute-categories`
  - `GET /api/v1/restriction-ingredients`
  - `GET /api/v1/menu-items`
  - `POST /api/v1/personal/recommendations/{requestId}/reroll`
- 관련 데이터
  - `member_taste_profiles`
  - `member_taste_profile_categories`
  - `member_taste_profile_restriction_ingredients`
  - `member_taste_profile_disliked_menu_items`
