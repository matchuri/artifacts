# 회원 탈퇴 기능

## 설명

- 사용자가 자신의 계정을 탈퇴 처리하는 기능이다.
- 탈퇴는 물리 삭제가 아니라 회원 상태를 비활성화하는 방식으로 처리한다.
- 탈퇴 후 사용자는 같은 계정으로 다시 로그인할 수 없다.

## 수용 기준

- 로그인한 사용자는 회원 탈퇴를 요청할 수 있다.
- 탈퇴 성공 시 회원 상태는 비활성 상태로 바뀐다.
- 탈퇴 후 보호 API 접근은 차단된다.
- 탈퇴 후 같은 계정으로 로그인할 수 없다.
- 탈퇴 확인 UI는 사용자의 명시적 확인을 받아야 한다.

## 엣지케이스

- 인증이 없거나 만료된 사용자가 탈퇴를 요청한다.
- 이미 비활성화된 회원이 탈퇴를 다시 요청한다.
- 탈퇴 직후 남아 있는 access token으로 API를 호출한다.
- 그룹 소유자가 탈퇴할 때 그룹 소유권 처리 정책이 필요하다.
- 탈퇴 후 재가입 가능 여부가 명확하지 않다.

## 참고

- 관련 API
  - `DELETE /api/v1/members/me`
- 관련 데이터
  - `members`
  - `auth_refresh_tokens`
  - `group_members`
  - `group_rooms`
- 미정 사항: 탈퇴 시 refresh token 폐기 범위, 그룹 소유자 탈퇴 정책, 탈퇴 계정 재가입 허용 여부
