# 메뉴 및 취향 참조 검색 기능

## 설명

- 사용자가 취향 입력과 메뉴 탐색에 필요한 참조 데이터를 조회하는 기능이다.
- 취향 선택 옵션은 `attribute category` 목록을 사용한다.
- 제한 재료는 `restriction ingredient` 목록을 사용한다.
- 비선호 메뉴 선택과 메뉴 탐색은 활성 메뉴 목록/상세 조회를 사용한다.

## 수용 기준

- 사용자는 활성 취향 속성 카테고리 목록을 조회할 수 있다.
- 사용자는 제한 재료를 이름과 알레르기 여부로 검색할 수 있다.
- 사용자는 활성 메뉴를 이름, 속성, 재료 조건으로 검색할 수 있다.
- 사용자는 메뉴 상세에서 속성, 재료, 대표 이미지를 확인할 수 있다.
- 비활성 참조 데이터는 공개 조회 결과에서 제외된다.
- 잘못된 필터 ID나 쿼리 파라미터는 실패한다.

## 엣지케이스

- 검색 결과가 없다.
- 잘못된 `categoryTypes` 값으로 조회한다.
- 존재하지 않거나 비활성화된 필터 ID를 사용한다.
- 메뉴 대표 이미지가 없다.
- 검색어가 비어 있거나 너무 짧다.
- 참조 데이터가 관리자에 의해 조회 직후 비활성화된다.

## 참고

- 관련 API
  - `GET /api/v1/attribute-categories`
  - `GET /api/v1/restriction-ingredients`
  - `GET /api/v1/menu-items`
  - `GET /api/v1/menu-items/{menuItemId}`
- 관련 데이터
  - `attribute_categories`
  - `ingredients`
  - `menu_items`
  - `menu_attribute_categories`
  - `menu_ingredients`
  - `menu_item_images`
- 미정 사항: 검색어 최소 길이, 검색 결과 정렬 기준 고도화, 비활성화된 기존 선택값 노출 정책
