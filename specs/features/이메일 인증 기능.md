# 이메일 인증 기능

## 설명

- 사용자가 회원가입, 로그인 ID 찾기, 비밀번호 재설정 등에 필요한 이메일 인증 코드를 발송하고 확인하는 기능이다.
- 인증 코드는 목적별로 발급되며, 확인 성공 시 후속 API에서 사용할 수 있는 인증 근거가 된다.
- 재발송, 만료, 잘못된 코드 입력을 사용자에게 명확히 안내한다.

## 수용 기준

- 사용자는 목적에 맞는 이메일 인증 코드를 요청할 수 있다.
- 사용자는 받은 인증 코드를 입력해 인증을 완료할 수 있다.
- 인증 성공 시 후속 흐름에서 사용할 수 있는 검증 결과가 반환된다.
- 만료되었거나 틀린 코드는 실패한다.
- 재발송 제한 시간 동안 중복 발송을 막거나 안내한다.
- 목적이 다른 인증 결과는 다른 흐름에서 사용할 수 없다.

### 시간과 횟수 제한

- 인증 코드: **6자리 숫자**
- 코드 유효 시간: **5분**
- 재전송 쿨다운: **60초**
- 틀린 코드 허용: **최대 5회**
- 인증 후 토큰 유효 시간: **10분**

## 엣지케이스

- 존재하지 않는 이메일로 계정 복구 인증을 요청한다.
- 같은 이메일로 인증 코드를 너무 자주 요청한다.
- 만료된 코드를 입력한다.
- 틀린 코드를 반복 입력한다.
- 다른 목적의 인증 토큰을 사용한다.
- 이메일 발송 자체가 실패한다.

## 참고

- 관련 API
  - `POST /api/v1/auth/email`
  - `POST /api/v1/auth/email/confirm`
- 관련 데이터
  - `auth_email_verifications`
- 미정 사항: 인증 코드 입력 제한 횟수, 재발송 쿨다운 문구, 이메일 발송 실패 시 재시도 정책
