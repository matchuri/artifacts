# 그룹 목록 조회 및 생성 기능

## 설명

- 사용자가 함께 점심 메뉴를 정할 그룹 방을 생성하고, 자신이 속한 그룹 목록을 확인하는 기능이다.
- 그룹 생성자는 그룹의 `OWNER`가 되며, 그룹 운영과 추천 시작 권한을 가진다.
- 그룹 목록은 사용자가 현재 참여 중인 그룹과 최신 추천 진행 상태를 빠르게 확인하게 한다.

## 수용 기준

- 로그인한 사용자는 그룹을 생성할 수 있다.
- 그룹 생성 시 생성자는 `OWNER` 멤버로 함께 저장된다.
- 그룹 생성 시 초대 코드가 생성된다.
- 사용자는 자신이 활성 멤버로 속한 그룹 목록을 조회할 수 있다.
- 그룹 목록에는 그룹명과 최신 추천 상태가 표시된다.
- 삭제되었거나 탈퇴한 그룹은 활성 목록에서 제외된다.
- 한 사용자당 가입할 수 있는 그룹의 최대 수는 10개이다. (TBD)

## 엣지케이스

- 인증이 없는 사용자가 그룹 생성을 시도한다.
- 그룹명이 비어 있거나 너무 길다.
- 위치 정보가 없거나 형식이 맞지 않는다.
- 그룹 생성 중 중복 제출이 발생한다.
- 소속 그룹이 하나도 없다.

## 참고

- 관련 API: `POST /api/v1/groups`, `GET /api/v1/groups`
- 관련 데이터: `group_rooms`, `group_members`, `group_invites`, `group_recommendations`
- 미정 사항: 그룹 최대 개수, 그룹 생성 시 위치 필수 여부, 그룹 목록 정렬 기준
