# 관리자 재료 관리 기능

## 설명

- 관리자가 메뉴 재료와 사용자 제한 재료 선택에 쓰이는 `ingredient` 기준 데이터를 관리하는 기능이다.
- 재료는 메뉴 구성 정보, 제한 재료 검색, 추천 후보 제외 조건에 영향을 준다.
- 알레르기 여부는 재료의 표시와 필터링에 사용된다.

## 수용 기준

- 관리자는 활성/비활성 재료 목록을 조회할 수 있다.
- 관리자는 새 재료를 생성할 수 있다.
- 관리자는 재료의 이름, 알레르기 여부, 정렬 순서, 활성 여부를 수정할 수 있다.
- 관리자는 재료를 비활성화할 수 있다.
- 중복 `code`는 생성할 수 없다.
- 일반 회원은 관리자 API를 사용할 수 없다.

## 엣지케이스

- 비관리자 회원이 접근한다.
- 중복 코드로 재료를 생성한다.
- 이미 메뉴나 회원 제한 재료에 연결된 재료를 비활성화한다.
- 알레르기 여부를 변경했을 때 기존 사용자 선택 표시가 달라진다.
- 비활성 재료를 다시 활성화한다.

## 참고

- 관련 API: `GET /api/v1/admin/ingredients`, `POST /api/v1/admin/ingredients`, `PATCH /api/v1/admin/ingredients/{ingredientId}`, `DELETE /api/v1/admin/ingredients/{ingredientId}`
- 관련 데이터: `ingredients`, `menu_ingredients`, `member_taste_profile_restriction_ingredients`
- 미정 사항: 알레르기 표시 문구, 연결된 데이터가 있을 때 비활성화 경고, 재료 병합 기능 필요 여부
