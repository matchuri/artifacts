# 로그인 상태 비밀번호 변경 기능

## 설명

- 자체 로그인 사용자가 로그인된 상태에서 현재 비밀번호를 확인한 뒤 새 비밀번호로 변경하는 기능이다.
- 계정 복구용 비밀번호 재설정과 달리 현재 세션은 유지하는 흐름이다.
- 소셜 로그인 전용 회원은 이 기능의 대상이 아니다.

## 수용 기준

- 로그인한 자체 회원은 현재 비밀번호와 새 비밀번호를 입력해 비밀번호를 변경할 수 있다.
- 현재 비밀번호가 일치해야 변경할 수 있다.
- 새 비밀번호는 비밀번호 정책을 통과해야 한다.
- 변경 성공 후 기존 access token과 refresh token은 유지된다.
- 변경 성공 후 기존 비밀번호로 로그인할 수 없다.
- 소셜 로그인 전용 회원에게는 비밀번호 변경 입력을 노출하지 않는다.

## 엣지케이스

- 현재 비밀번호가 틀렸다.
- 새 비밀번호가 형식 정책에 맞지 않는다.
- 새 비밀번호와 확인 비밀번호가 다르다.
- 소셜 로그인 전용 회원이 직접 API를 호출한다.
- 인증이 만료된 상태에서 변경을 시도한다.

## 참고

- 관련 API
  - `PATCH /api/v1/members/me/password`
- 관련 데이터
  - `members`
  - `auth_refresh_tokens`
- 미정 사항: 비밀번호 변경 후 전체 세션 유지 여부 장기 정책, 변경 완료 알림 방식, 최근 사용 비밀번호 제한 여부
