# 로그인 세션 기능

## 설명

- 사용자가 로그인하고, access token 만료 시 refresh token으로 세션을 이어가며, 로그아웃으로 현재 세션을 종료하는 기능이다.
- 로그인 응답은 사용자가 다음에 이동해야 할 온보딩 상태를 함께 제공한다.
- refresh token은 서버 저장 기준으로 재발급과 무효화를 관리한다.

## 수용 기준

- 사용자는 로그인 ID와 비밀번호로 로그인할 수 있다.
- 로그인 성공 시 access token, refresh token, 온보딩 상태가 반환된다.
- access token이 만료되면 refresh token으로 새 access token을 발급받을 수 있다.
- 로그아웃하면 현재 refresh token은 더 이상 사용할 수 없다.
- 비활성 회원이나 잘못된 비밀번호로는 로그인할 수 없다.
- 온보딩 미완료 회원은 로그인은 가능하지만 핵심 API 접근은 제한된다.

## 엣지케이스

- 로그인 ID가 존재하지 않는다.
- 비밀번호가 틀렸다.
- 탈퇴 또는 비활성 상태의 회원이 로그인한다.
- refresh token이 만료되었거나 서버에 존재하지 않는다.
- 로그아웃 후 같은 refresh token으로 재발급을 시도한다.
- 여러 기기 세션 중 하나만 로그아웃한다.

## 참고

- 관련 API
  - `POST /api/v1/auth/login`
  - `POST /api/v1/auth/refresh`
  - `POST /api/v1/auth/logout`
- 관련 데이터
  - `members`
  - `auth_refresh_tokens`
  - `member_agreements`
- 미정 사항: 전체 기기 로그아웃 지원 여부, refresh token 회전 정책, access token 만료 시 프론트 재시도 UX
