# 비밀번호 재설정 기능

## 설명

- 사용자가 로그인하지 않은 상태에서 이메일 인증을 통해 로컬 계정 비밀번호를 새로 설정하는 기능이다.
- 비밀번호 재설정은 계정 복구 흐름이며, 로그인 상태 비밀번호 변경과 구분한다.
- 성공 후 기존 세션 무효화 정책을 명확히 적용한다.

## 수용 기준

- 사용자는 계정 식별 정보와 이메일 인증을 통해 비밀번호 재설정을 시작할 수 있다.
- 인증에 성공한 사용자는 새 비밀번호를 설정할 수 있다.
- 새 비밀번호는 비밀번호 정책을 통과해야 한다.
- 재설정 성공 후 기존 비밀번호로는 로그인할 수 없다.
- 유효하지 않거나 만료된 인증으로는 비밀번호를 바꿀 수 없다.
- 소셜 전용 계정은 비밀번호 재설정 대상이 아니다.

## 엣지케이스

- 존재하지 않는 계정으로 재설정을 요청한다.
- 이메일 인증이 만료된다.
- 새 비밀번호와 확인 비밀번호가 다르다.
- 새 비밀번호가 정책에 맞지 않는다.
- 소셜 전용 회원이 비밀번호 재설정을 시도한다.
- 재설정 성공 후 기존 refresh token 처리 정책이 적용되지 않는다.

## 참고

- 관련 API: `POST /api/v1/auth/email`, `POST /api/v1/auth/email/confirm`, `POST /api/v1/auth/recovery/password`
- 관련 데이터: `members`, `auth_email_verifications`, `auth_refresh_tokens`
- 미정 사항: 재설정 후 자동 로그인 여부, 모든 세션 로그아웃 문구, 인증 완료 상태 저장 위치
