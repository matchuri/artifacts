# 실시간 이벤트 기능

## 설명

- 사용자가 그룹 초대, 그룹 추천 진행, 투표, 최종 확정 같은 변화를 새로고침 없이 받는 기능이다.
- 개인 이벤트 스트림은 사용자 단위 알림을 전달한다.
- 그룹 이벤트 스트림은 그룹 상세와 그룹 추천 화면의 상태 변화를 전달한다.
- 실제 서비스는 `EventSourcePolyfill`을 사용하며, `/realtime-lab`의 직접 구현 fetch client와 구분한다.

## 수용 기준

- 로그인·온보딩 완료 후 공통 영역에서 개인 SSE 이벤트 스트림에 연결한다.
- 그룹 멤버는 그룹 SSE 이벤트 스트림에 연결할 수 있다.
- 개인 연결 완료와 초대 생성 이벤트 수신 시 초대 목록과 존재 여부를 재조회한다.
- 그룹 추천 시작, 준비 상태 변경, 투표 변경, 최종 확정 이벤트는 각 화면의 callback에 따라 상태 반영 또는 REST 재조회로 처리한다.
- 그룹 스트림은 오류 기록 후 연결을 닫고 해당 연결의 자동 재시도를 중단한다. 화면 재진입·새로고침 또는 hook effect 재실행 시 새 연결을 만든다.
- 개인 스트림은 오류만 기록하고 polyfill의 네트워크 오류 재연결 동작을 유지한다.
- 오프라인 이벤트 저장·재전송과 그룹 연결 완료 시 일괄 보정 조회는 제공하지 않는다.
- 권한이 없는 사용자는 그룹 이벤트 스트림에 연결할 수 없다.

## 엣지케이스

- 인증이 만료된 상태로 SSE에 연결한다.
- 그룹 멤버가 아닌 사용자가 그룹 이벤트를 구독한다.
- 네트워크 문제로 연결이 반복적으로 끊긴다.
- 이벤트 수신 순서가 바뀌거나 일부 누락된다.
- 화면이 이미 이동한 뒤 이벤트가 도착한다.
- 연결 중 access token이 만료되거나 변경된다.

## 참고

- 관련 API
  - `GET /api/v1/realtime/events`
  - `GET /api/v1/groups/{groupId}/realtime/events`
- 관련 데이터
  - 실시간 emitter/connection 상태
  - `group_invites`
  - `group_recommendations`
  - `group_recommendation_votes`
- 개선 제안(후속 검토): 그룹 스트림의 제한된 재시도와 재연결 후 REST 보정 조회, 인증·권한 오류별 종료 정책을 검토한다.
