# 실시간 이벤트 기능

## 설명

- 사용자가 그룹 초대, 그룹 추천 진행, 투표, 최종 확정 같은 변화를 새로고침 없이 받는 기능이다.
- 개인 이벤트 스트림은 사용자 단위 알림을 전달한다.
- 그룹 이벤트 스트림은 그룹 상세와 그룹 추천 화면의 상태 변화를 전달한다.

## 수용 기준

- 로그인한 사용자는 개인 SSE 이벤트 스트림에 연결할 수 있다.
- 그룹 멤버는 그룹 SSE 이벤트 스트림에 연결할 수 있다.
- 그룹 초대 생성, 그룹 추천 시작, 준비 상태 변경, 투표 변경, 최종 확정 이벤트가 필요한 화면에 반영된다.
- SSE 연결이 끊기면 클라이언트는 재연결을 시도할 수 있다.
- 권한이 없는 사용자는 그룹 이벤트 스트림에 연결할 수 없다.

## 엣지케이스

- 인증이 만료된 상태로 SSE에 연결한다.
- 그룹 멤버가 아닌 사용자가 그룹 이벤트를 구독한다.
- 네트워크 문제로 연결이 반복적으로 끊긴다.
- 이벤트 수신 순서가 바뀌거나 일부 누락된다.
- 화면이 이미 이동한 뒤 이벤트가 도착한다.

## 참고

- 관련 API: `GET /api/v1/realtime/events`, `GET /api/v1/groups/{groupId}/realtime/events`
- 관련 데이터: 실시간 emitter/connection 상태, `group_invites`, `group_recommendations`, `group_recommendation_votes`
- 미정 사항: 재연결 간격, 이벤트 유실 보정 조회 정책, 토스트/배지 노출 기준
