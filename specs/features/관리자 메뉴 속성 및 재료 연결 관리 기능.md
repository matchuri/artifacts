# 관리자 메뉴 속성 및 재료 연결 관리 기능

## 설명

- 관리자가 메뉴와 속성 카테고리, 메뉴와 재료의 연결을 관리하는 기능이다.
- 이 연결은 추천 알고리즘이 메뉴를 점수화하거나 제외하는 기준 데이터가 된다.
- 연결 수정은 공개 메뉴 상세와 추천 결과에 즉시 영향을 줄 수 있다.

## 수용 기준

- 관리자는 메뉴의 속성 카테고리 연결을 전체 교체 방식으로 수정할 수 있다.
- 관리자는 메뉴의 재료 연결을 전체 교체 방식으로 수정할 수 있다.
- 연결 대상은 활성 속성 카테고리와 활성 재료만 허용된다.
- 중복 연결 ID는 실패한다.
- 수정 성공 후 메뉴 상세에서 최신 연결 상태가 반환된다.
- 일반 회원은 연결 관리 API를 사용할 수 없다.

## 엣지케이스

- 존재하지 않는 메뉴에 연결을 수정한다.
- 비활성 속성 카테고리 또는 재료를 연결한다.
- 중복 ID가 요청에 포함된다.
- 연결을 모두 빈 배열로 저장한다.
- 추천이 진행 중일 때 기준 데이터가 변경된다.

## 참고

- 관련 API: `PATCH /api/v1/admin/menu-items/{menuItemId}/references`
- 관련 데이터: `menu_items`, `attribute_categories`, `ingredients`, `menu_attribute_categories`, `menu_ingredients`
- 미정 사항: 연결 변경 이력 관리, 진행 중 추천에 변경 사항을 반영할지 여부, 빈 연결 메뉴의 추천 제외 여부
