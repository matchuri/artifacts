# 회원 개인 추천 시작 기능

## 설명

- 로그인한 사용자가 저장된 취향 프로필을 바탕으로 개인 메뉴 추천을 시작하는 기능이다.
- 추천 요청은 상태를 가지는 실행 단위로 저장된다.
- 열린 개인 추천이 있으면 새 추천 생성을 제한해 사용자가 하나의 결정 흐름에 집중하도록 한다.

## 수용 기준

- 로그인한 사용자는 개인 추천을 시작할 수 있다.
- 추천 시작 시 저장된 취향 프로필이 반영된다.
- 제한 재료, 비선호 메뉴, 최근 선택 메뉴는 후보 제외 조건으로 사용된다.
- 열린 개인 추천이 있으면 새 추천 시작은 실패한다.
- 24시간이 지난 열린 추천은 만료 처리 후 새 추천을 만들 수 있다.
- 추천 생성 성공 시 후보 목록을 확인할 수 있는 추천 ID가 반환된다.

## 엣지케이스

- 취향 프로필이 없는 사용자가 추천을 시작한다.
- 열린 추천이 이미 존재한다.
- 기존 열린 추천이 시간상 만료되었다.
- 추천 가능한 메뉴 후보가 부족하다.
- 추천 알고리즘 또는 후보 저장이 실패한다.

## 참고

- 관련 API
  - `POST /api/v1/personal/recommendations`
  - `GET /api/v1/personal/recommendations/{requestId}`
  - `GET /api/v1/personal/recommendations/{requestId}/candidates`
- 관련 데이터
  - `personal_recommendations`
  - `personal_recommendation_candidates`
  - `member_taste_profiles`
  - `member_menu_actions`
- 미정 사항: 취향 프로필이 없을 때 이동할 화면, 후보 부족 시 사용자 문구, 추천 시작 전 위치 입력 필요 여부
