# 회원 개인 추천 시작 기능

## 설명

- 로그인하고 필수 약관 동의를 완료한 회원이 저장된 취향 프로필을 바탕으로 개인 메뉴 추천을 시작하는 기능이다.
- 추천 요청은 상태와 요청 시각을 가지는 실행 단위로 저장되고 후보도 추천 실행에 종속되어 저장된다.
- 후보 계산은 선호 속성과 과거 선택 속성을 점수에 반영하고, 제한 재료·비선호 메뉴·최근 선택 메뉴·최근 `SKIP` 메뉴를 제외한다.
- 사용자에게 동시에 하나의 유효한 결정 흐름만 제공하기 위해 열린 개인 추천이 있으면 일반 신규 생성을 제한한다.
- MVP v1에서는 요청의 선택적 `contextJson`을 점수 계산에 사용하지 않으며, 생성 시 추천 엔티티의 `contextJson`도 저장하지 않는다.

## 정량 제약사항

- 회원별 유효한 `OPEN` 개인 추천은 최대 1개다.
- 미선택 `OPEN` 추천은 `requestedAt + 24시간`부터 만료로 판정한다.
- 한 추천에서 생성하는 후보는 최대 3개이며, 조건을 만족하는 메뉴가 부족하면 0~2개일 수 있다.
- 최근 최종 선택 이력 최대 3건의 메뉴를 신규 후보에서 제외한다. 이 제외에는 별도 시간 제한이 없다.
- `SKIP` 메뉴는 행동 로그 생성 시각부터 24시간 동안 제외한다.
- 외부에 노출하는 후보 점수는 선호 속성 일치와 과거 선택 속성 빈도를 반영해 0~100 범위, 소수점 첫째 자리로 정규화한다.

## 수용 기준

- 로그인하고 필수 약관 동의를 완료한 활성 회원은 개인 추천을 시작할 수 있다.
- 회원에게 저장된 취향 프로필이 없으면 개인 추천 생성을 거절한다.
- 회원의 선호 속성은 점수에 반영하고, 제한 재료와 비선호 메뉴는 후보 제외 조건으로 반영한다.
- 최근 최종 선택 이력 최대 3건의 메뉴와 최근 24시간 `SKIP` 메뉴를 후보에서 제외한다.
- 후보는 알고리즘의 내부 합산 점수 내림차순으로 정렬하고 내부 합산 점수가 같으면 메뉴 ID 오름차순으로 정렬하며, 순위는 1부터 부여한다.
- 열린 개인 추천이 있으면 새 추천을 만들지 않고 기존 추천 ID를 포함한 충돌 오류를 반환한다.
- 24시간이 지난 미선택 추천은 `EXPIRED`와 `closedAt`을 기록한 뒤 새 추천을 생성할 수 있다.
- 추천 생성 성공 시 `requestId`, `OPEN` 상태, `requestedAt`, `closedAt=null`, 후보 목록을 반환한다.
- 후보에는 후보 ID, 메뉴 ID, 메뉴명, 대표 이미지 URL, 순위, 추천 점수가 포함되며 대표 이미지가 없으면 `thumbnailUrl`은 `null`이다.
- 추천 실행 단위와 생성된 후보를 저장하고 이후 상세 조회·선택에 같은 추천 ID를 사용한다.

## 엣지케이스

- 비로그인, 비활성 또는 필수 약관 미동의 회원이 추천을 시작한다.
- 취향 프로필이 없는 회원이 추천을 시작한다.
- 열린 추천이 이미 존재한다.
- 기존 열린 추천이 정확히 24시간 만료 경계에 도달했다.
- 제한 재료, 비선호 메뉴, 최근 선택 메뉴, 최근 `SKIP` 메뉴가 후보를 모두 제외한다.
- 취향과 선택 이력으로 얻는 점수가 없어 모든 후보의 정규화 점수가 0이다.
- 동일 점수 후보가 여러 개다.
- 추천 시작 요청을 빠르게 반복하거나 동시에 보낸다.
- 추천 알고리즘 또는 추천·후보 저장이 실패한다.

## 참고

- 관련 API
  - `POST /api/v1/personal/recommendations`
  - `GET /api/v1/personal/recommendations/{requestId}`
  - `GET /api/v1/personal/recommendations/{requestId}/candidates`
- 관련 데이터
  - `personal_recommendations`
  - `personal_recommendation_candidates`
  - `member_taste_profiles`
  - `member_menu_actions`
  - `menu_items`, `menu_attribute_categories`, `menu_ingredients`
- 미정 사항:
  - 취향 프로필이 없을 때 이동할 화면
  - 후보가 없거나 3개 미만일 때의 사용자 안내
  - 추천 시작 전 위치 입력 필요 여부와 `contextJson` 활용 시점
  - 동시 생성 요청의 서버 측 잠금 또는 멱등성 보장 방식
