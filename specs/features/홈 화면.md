# 홈 화면

## 설명

- 로그인한 회원이 점심 메뉴 추천을 시작하거나 진행 중인 추천으로 돌아가고, 자신의 설정과 최근 활동을 확인하는 화면이다.
- 대상 화면은 회원 홈(`/home`)이며 사용자 정보·위치, 개인 추천 진입 버튼, 취향 프로필, 지난 메뉴 추천 기록, 최근 그룹 활동, 그룹 초대 알림으로 구성한다.
- 회원·개인 추천·그룹 데이터를 홈 API로 모아 조회한다. 초대 알림은 별도 API와 실시간 이벤트로 조회·갱신한다.
- 비로그인 메인 화면과 추천 결과·투표·최종 메뉴 확정의 상세 동작은 각각의 기능에서 관리한다.

## 수용 기준

### 접근 및 조회 상태

- 인증과 필수 약관·닉네임 온보딩을 완료한 활성 회원은 홈에 접근할 수 있다.
- 비로그인 사용자와 인증이 만료되거나 비활성인 회원은 비로그인 메인(`/`)으로 이동한다. 필수 약관 미완료 시 약관 화면, 닉네임 미완료 시 닉네임 설정 화면으로 이동한다.
- 소셜 회원가입 진행 상태에서는 필수 온보딩 완료 후에도 가입 흐름의 취향 설정 화면으로 이동하며, 가입 흐름이 종료되어야 홈에 진입한다.
- 인증 확인 중이거나 최초 홈 데이터를 불러오는 동안 스켈레톤을 표시한다.
- 최초 조회 실패 시 오류와 `다시 시도` 버튼을 제공한다. 기존 홈 데이터가 있는 상태에서 재조회하면 기존 화면을 유지한다.
- 홈 API의 일부 도메인 조회가 실패하면 전체 요청을 실패 처리한다. 조회 실패를 이력이나 설정이 없는 정상 상태로 바꾸지 않는다.

### 사용자 정보·위치·취향

- 상단에 닉네임과 현재 프로필 이미지를 표시한다. 이미지 URL이 없으면 기본 사용자 아이콘을 표시한다.
- 위치 영역에는 저장된 검색 기준 주소를 표시한다. 위치가 없으면 `설정된 위치가 없습니다.`를 표시하며, 저장 주소를 기기의 현재 GPS 위치로 취급하지 않는다.
- 위치 영역을 누르면 위치 설정 창을 연다. 위치 정보를 불러오는 중에는 대기 안내를 표시한다.
- 위치 저장 성공 후 홈을 재조회하고 설정 창을 닫는다. 저장 실패 시 오류를 안내하고 설정 창을 유지한다.
- 취향 프로필에는 선택한 취향 카테고리 이름을 최대 3개 표시하고 나머지는 `+개수`로 표시한다. 제한 재료와 비선호 메뉴는 홈 요약에서 제외한다.
- 취향이 없으면 `설정된 취향이 없습니다.`를 표시한다. `수정`으로 취향 설정 창을 열고 저장 성공 후 홈을 재조회한다.

### 개인 추천 시작 및 이어보기

- 가장 최근 개인 추천의 상태가 `OPEN`이고 추천 ID가 있으면 `진행 중인 메뉴 추천 보기` 버튼을 표시하고 해당 결과 화면으로 이동한다.
- 최신 추천이 없거나 `OPEN`이 아니면 `메뉴 추천 시작하기` 버튼을 표시한다. 최신 추천은 요청 시각 내림차순, 같은 시각이면 ID 내림차순으로 판단한다.
- 신규 추천을 시작하려면 화면에서 저장 위치와 필수 취향 설정 여부를 확인한다. 조건을 충족하지 않으면 설정 안내 창을 표시하고 추천 생성 요청을 보내지 않는다.
- 추천 생성 중에는 로딩 화면을 표시하고 반복 요청을 막는다. 성공하면 생성된 추천 결과로 이동하고, 실패하면 오류를 안내해 홈에서 다시 시도할 수 있게 한다.
- 진행 중인 추천으로 이동할 때는 신규 추천을 생성하지 않는다.

### 지난 메뉴 추천 기록

- 최종 메뉴를 선택한 `SELECTED` 개인 추천을 요청 시각 내림차순, 같은 시각이면 추천 ID 내림차순으로 최대 3건 표시한다.
- 각 기록에는 추천 요청 날짜, 조회 시점의 선택 메뉴명, 현재 활성 속성 중 음식 분류를 표시한다. 날짜는 메뉴 선택 완료일이 아니다.
- 기록을 누르면 해당 개인 추천 결과로 이동하고, `전체 보기`를 누르면 개인 추천 이력 화면으로 이동한다.
- 선택 이력이 없으면 `메뉴 추천 기록이 없습니다.`를 표시한다. 메뉴가 비활성화되어도 기존 선택 이력은 유지한다.

### 최근 그룹 활동

- 현재 가입 상태가 `ACTIVE`이고 삭제되지 않은 그룹의 추천 세션을 대상으로 최근 활동을 표시한다. 추천 세션이 없는 그룹과 탈퇴·강퇴된 그룹은 제외한다.
- 하나의 추천 세션은 현재 또는 최종 상태로 한 번 표시한다. 같은 그룹의 서로 다른 추천 세션은 각각 표시할 수 있으며, 그룹 방이 `CLOSED`라는 이유만으로 이력을 제외하지 않는다.
- 활동 시각 내림차순, 같은 시각이면 추천 ID 내림차순으로 홈에 최대 3건 표시한다. 홈 API는 그룹 활동 전체를 반환하며 화면에서 표시 건수를 제한한다.
- `PREPARING`은 추천 준비, `OPEN`은 투표 진행, `FINALIZED`는 확정 메뉴를 안내한다. 취소·실패·만료·재추천으로 종료된 상태는 종료 안내를 표시한다.
- 상대시간은 준비 상태의 생성 시각, 투표 상태의 시작 시각, 종료 상태의 종료 시각을 기준으로 표시한다. 전원이 투표했더라도 그룹장이 확정하기 전에는 투표 진행 상태다.
- 활동을 누르면 그룹 ID로 해당 그룹 상세에 진입한다. `전체 보기`를 누르면 최근 그룹 활동 전체 화면으로 이동한다.
- 활동이 없으면 `최근 그룹 활동이 없습니다.`를 표시한다.

### 그룹 초대 알림 및 갱신

- 초대 존재 여부를 알림 버튼에 표시하고, 버튼을 누르면 받은 초대 목록을 열거나 닫을 수 있다.
- 사용자는 초대를 수락하거나 거절할 수 있으며, 응답 처리 중에는 중복 응답을 막는다.
- 초대 응답 성공 후 초대 목록·초대 존재 여부·홈 데이터를 재조회한다. 초대 생성 실시간 이벤트를 받으면 초대 목록과 존재 여부를 갱신한다.
- 홈의 그룹 활동 목록과 초대 알림은 별개다. 그룹 활동을 읽음 상태가 있는 알림함이나 상태 전환별 이벤트 이력으로 취급하지 않는다.

## 엣지케이스

- 인증 확인이 늦어지거나 홈 조회 중 필수 약관·닉네임 완료 상태가 변경된다.
- 신규 회원에게 위치·취향·선택 이력·그룹 활동이 없거나, 프로필 이미지가 없는 기존 회원이 진입한다.
- 홈은 조회됐지만 추천 시작 판단에 쓰는 별도 위치·취향 조회가 지연되거나 실패한다.
- 위치·취향 저장은 성공했지만 홈 재조회가 실패해 이전 요약이 화면에 남는다.
- 홈 조회 뒤 기존 `OPEN` 추천이 만료되거나 다른 기기에서 선택 완료된다.
- 추천 시작 버튼을 누르기 전에 다른 기기에서 새 추천을 생성하여 열린 추천 충돌이 발생한다.
- 개인 이력의 요청 시각이 같거나, 선택했던 메뉴명·속성·활성 상태가 변경된다.
- 같은 그룹의 추천 활동이 여러 건이거나 활동 시각이 같으며, 그룹 방은 종료됐지만 가입 상태는 유지된다.
- 홈 조회 뒤 그룹에서 탈퇴·강퇴되거나 그룹이 삭제되어 활동을 눌렀을 때 상세에 접근할 수 없다.
- 초대 목록을 연 뒤 초대가 취소되거나 다른 기기에서 이미 응답한다.
- 실시간 연결이 끊기거나 다른 화면에서 프로필 이미지·그룹 상태가 변경되어 홈 표시가 최신 상태와 달라진다.
- 그룹 활동의 기준 시각이 없거나 클라이언트 시간·시간대 차이로 상대시간이 달라진다.
- 그룹 추천 이력이 많아 홈 응답과 활동 전체 화면의 표시량이 커진다.

## 참고

- 관련 API
  - `GET /api/v1/home`: 사용자 정보, 최신 개인 추천, 위치, 취향 요약, 선택 이력, 그룹 활동 조회
  - `POST /api/v1/personal/recommendations`: 개인 추천 생성
  - `GET /api/v1/invites/me/exists`: 그룹 초대 존재 여부 조회
  - 초대 목록·응답 및 실시간 이벤트 API는 그룹 초대 기능과 실시간 이벤트 기능에서 관리
- 관련 데이터
  - `members`, `member_profile_images`, `image_assets`
  - `member_locations`, `member_taste_profiles`, `member_taste_profile_categories`
  - `personal_recommendations`, `personal_recommendation_candidates`, `menu_items`, `menu_attribute_categories`
  - `group_rooms`, `group_room_members`, `group_recommendations`, `group_invites`
  - 홈 전용 테이블은 생성하지 않고 기존 도메인 데이터를 조합
- 관련 기능
  - 인증 및 온보딩 라우팅 가드 기능
  - 프로필 이미지 설정 기능
  - 위치 설정 기능
  - 내 취향 프로필 관리 기능
  - 회원 개인 추천 시작 기능
  - 개인 추천 결과 및 후보 선택 기능
  - 개인 추천 이력 조회 기능
  - 그룹 상세 및 관리 기능
  - 그룹 초대 기능
  - 실시간 이벤트 기능
- 구현 기준
  - 워크스페이스 `docs/api/home.md`
  - 프론트엔드 `src/app/home/page.tsx`, `src/features/home/`
- 미정 사항:
  - 기존 데이터가 있는 상태에서 홈 재조회 실패 시 갱신 실패 안내 방식
  - 별도 위치·취향 조회 실패와 미설정 상태를 구분하는 안내
  - 다른 화면·기기 변경 및 실시간 재연결 후 홈 전체 갱신 시점
  - 그룹 활동 상대시간의 시간대 해석 기준 통일과 대량 이력의 페이지네이션
