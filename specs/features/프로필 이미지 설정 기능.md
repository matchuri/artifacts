# 프로필 이미지 설정 기능

## 설명

- 사용자가 서비스에서 제공하는 프리셋 이미지 중 하나를 자신의 프로필 이미지로 설정하는 기능이다.
- 마이페이지(`/settings`)의 프로필 이미지 수정 버튼으로 선택 창을 열고, 이미지를 선택한 뒤 `변경하기`로 저장한다.
- 자체 회원가입과 최초 소셜 회원 생성 시 현재 기본 프리셋을 자동 설정한다. 사용자가 별도로 이미지를 선택하는 것은 필수 온보딩 항목이 아니다.
- 회원별 현재 이미지 한 건만 유지하며 변경 이력은 저장하지 않는다.
- 사용자 파일 업로드, 이미지 편집, 이미지 삭제 및 미설정 상태로 초기화는 현재 제공 범위에 포함하지 않는다. 프리셋 추가·삭제·기본값 지정은 관리자 운영 기능이다.

## 수용 기준

- 필수 약관과 닉네임 온보딩을 완료한 로그인 사용자는 마이페이지에서 현재 프로필 이미지와 수정 버튼을 볼 수 있다.
- 이미지 연결이 없는 기존 회원은 기본 사용자 아이콘을 볼 수 있으며, 프리셋을 선택해 최초 이미지를 설정할 수 있다.
- 선택 창을 열면 삭제되지 않은 활성 프리셋을 ID 오름차순으로 조회한다. 목록에는 프리셋 ID, 공개 이미지 URL, 기본 프리셋 여부가 포함된다.
- 현재 프로필 이미지 URL과 일치하는 프리셋이 있으면 해당 항목을 선택한 상태로 표시한다. 일치 항목이 없으면 선택하지 않은 상태로 시작한다.
- 사용자는 한 번에 하나의 프리셋을 선택할 수 있으며, 선택 표시와 큰 미리보기로 저장할 이미지를 확인할 수 있다.
- 이미지를 선택하는 것만으로는 저장되지 않는다. 저장 전에 선택 창을 닫으면 기존 프로필 이미지가 유지되고, 다시 열 때 저장된 이미지를 기준으로 선택 상태를 구성한다.
- 목록을 불러오는 동안 로딩 상태를 표시한다. 목록 조회 실패 시 오류와 `다시 시도` 버튼을 제공한다.
- 선택한 이미지가 없거나 목록을 불러오는 중이면 `변경하기` 버튼을 비활성화한다.
- 저장 중에는 `변경 중...`을 표시하고 저장 버튼, 이미지 선택, 닫기 버튼을 비활성화한다.
- 저장 요청은 로그인한 본인의 프로필에만 적용되며, 선택한 `presetProfileImageId`를 전달한다. 닉네임과 취향 정보는 변경하지 않는다.
- 저장 성공 시 반환된 이미지 URL을 마이페이지에 즉시 반영하고 선택 창을 닫는다. 이후 내 기본 정보를 다시 조회해도 저장된 이미지가 유지된다.
- 저장 실패 시 오류를 안내하고 선택 창을 유지해 재시도할 수 있게 한다. 마이페이지의 이미지는 성공 응답을 받기 전까지 교체하지 않는다.
- 현재와 같은 프리셋을 다시 저장할 수 있으며, 회원 이미지 연결이나 변경 이력이 추가로 생성되지 않는다.
- 관리자가 사용 중인 프리셋을 삭제하면 해당 회원의 이미지는 현재 기본 프리셋으로 자동 변경되고, 이후 프로필 조회에 반영된다.

## 엣지케이스

- 인증이 없거나 만료된 사용자, 탈퇴 또는 비활성 회원이 접근한다.
- 필수 약관 미완료 회원이 목록 조회 또는 설정을 요청하거나, 닉네임 미완료 회원이 목록 조회를 요청한다.
- 현재 프로필 이미지가 `null`이거나 현재 이미지 URL과 일치하는 항목이 목록에 없다.
- 목록이 비어 있어 선택할 수 있는 이미지가 없다. 선택값 없이 저장하지 않으며, 빈 목록 전용 안내는 미정이다.
- 목록 조회에 실패한 뒤 재시도하거나, 목록을 불러오는 중 선택 창을 닫고 다시 연다.
- 이미지 URL은 반환되지만 실제 이미지 로딩이 실패한다. 대체 이미지 표시 정책은 미정이다.
- 선택만 하고 저장하지 않은 채 창을 닫거나, 기존과 같은 프리셋을 저장한다.
- 저장 중 버튼을 반복해서 누르거나 다른 이미지 선택 또는 닫기를 시도한다.
- 목록 조회 후 저장 전에 선택한 프리셋이 삭제되어 `IMAGE_PRESET_PROFILE_NOT_FOUND`가 반환된다.
- 서버 저장은 완료됐지만 응답 수신에 실패한다. 재조회 전까지 화면과 서버 상태가 다를 수 있으며, 동일 프리셋 재요청으로 연결이 중복 생성되지 않는다.
- 여러 탭이나 기기에서 서로 다른 이미지를 동시에 저장한다. 충돌 안내와 다른 화면 갱신 방식은 미정이다.
- 사용 중인 프리셋 삭제로 서버 이미지가 기본 프리셋으로 변경됐지만 이미 열린 화면에는 이전 이미지가 남아 있다.

## 참고

- 관련 API
  - `GET /api/v1/members/me`: 현재 `profileImageUrl` 조회
  - `GET /api/v1/members/profile/preset-image`: 선택 가능한 프리셋 목록 조회
  - `PUT /api/v1/members/profile/preset-image`: 본인 이미지 설정, `profileImageId`, `presetProfileImageId`, `imageUrl`, `updatedAt` 반환
- 관련 데이터
  - `members`: 설정 대상 회원
  - `member_profile_images`: 회원별 현재 이미지 연결 한 건
  - `preset_profile_images`: 활성 프리셋 및 기본 여부
  - `image_assets`: 여러 회원이 공유하는 이미지 자산
- 관련 기능
  - 내 기본 정보 관리 기능
- 구현 기준
  - 워크스페이스 `docs/api/member-profile-image.md`, `docs/data/policies.md`
  - 프론트엔드 `src/app/settings/page.tsx`, `src/features/settings/application/hooks/usePresetProfileImage.ts`, `src/features/settings/ui/components/ProfileImageChangeModal.tsx`
  - 백엔드 `src/main/java/matchuri/backend/domain/member/support/profile/MemberProfileImageManager.java`
- 미정 사항: 빈 목록 안내 문구, 이미지 로딩 실패 시 대체 표시, 삭제된 프리셋 저장 실패 후 목록 자동 갱신 여부, 동시 변경 충돌 안내, 홈·초대 목록 등 이미 열린 다른 화면의 이미지 갱신 시점
