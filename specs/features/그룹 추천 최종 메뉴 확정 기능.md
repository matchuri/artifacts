# 그룹 추천 최종 메뉴 확정 기능

## 설명

- 그룹 `OWNER`가 투표 결과를 바탕으로 최종 메뉴를 확정하는 기능이다.
- 최종 메뉴는 그룹 추천 후보 중 하나여야 한다.
- 확정 후 그룹원은 결정된 메뉴와 투표 결과를 확인할 수 있다.

## 수용 기준

- `OWNER`는 열린 그룹 추천 세션을 최종 확정할 수 있다.
- 최종 메뉴는 추천 후보 중 하나로 결정된다.
- 동률이면 정해진 우선순위 기준으로 최종 메뉴를 선택한다.
- 확정 후 추천 세션은 더 이상 투표할 수 없는 상태가 된다.
- 그룹원은 결과 화면에서 최종 메뉴와 투표 현황을 확인할 수 있다.
- 최종 확정 이벤트는 그룹 실시간 이벤트로 반영될 수 있다.

## 엣지케이스

- 일반 멤버가 최종 확정을 시도한다.
- 투표가 하나도 없는 상태에서 확정한다.
- 동률 후보가 여러 개다.
- 이미 확정된 세션을 다시 확정한다.
- 준비 중이거나 취소된 세션을 확정한다.
- 확정 직전 멤버 또는 후보 상태가 바뀐다.

## 참고

- 관련 API: `PATCH /api/v1/groups/{groupId}/recommendations/{sessionId}/finalize`, `GET /api/v1/groups/{groupId}/recommendations/{sessionId}`, `GET /api/v1/groups/{groupId}/realtime/events`
- 관련 데이터: `group_recommendations`, `group_recommendation_candidates`, `group_recommendation_votes`, `group_members`
- 미정 사항: 무투표 확정 허용 여부, 동률 처리 노출 문구, 확정 후 식당 탐색 연결 방식
