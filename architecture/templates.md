# 아키텍처 산출물 템플릿

## 모듈 경계·의존성 지도

```markdown
# 대상 모듈 경계·의존성 지도

## 기준과 상태

- 상태: 검토 초안 / 채택 / 대체됨
- 확인일: YYYY-MM-DD
- 기준 커밋: backend commit SHA
- 작업 트리: 관련 미커밋 변경 여부
- 현재 사실과 제안의 구분, 조사 범위와 한계

## 현재 의존성

현재 패키지 참조 지도, 순환과 대표 코드 근거.

## 제안 모듈 경계

모듈 ID | 책임과 데이터 소유권 | 공개 계약 | 허용 의존

## 제안 의존성

flowchart LR Mermaid 그래프. 화살표는 컴파일 의존이며 런타임 이벤트 전달과 구분.

## 경계별 정합성

다른 영역을 함께 변경하는 흐름, FK·cascade·조회 조합 책임.

## 결정 사항

항목 | 미결정/확정/보류 상태 | 권고안·결정 내용·적용 범위

## 근거

코드와 개발 문서 링크.
```

## 트랜잭션 분류표

```markdown
# 대상 트랜잭션 분류표

## 기준과 상태

확인일, 기준 커밋, 작업 트리 상태와 제안의 효력.

## 분류 기준

원자적 쓰기 / 순수 조회 / 만료를 저장하는 조회 / 커밋 후 부수 효과 / 외부 연동 / 항목별 배치.

## 트랜잭션 분류표

ID | 실제 진입점 | 현재 경계·변경 | 보존할 정합성과 제안 분류

## 예외와 커밋

기본 롤백과 noRollbackFor, 상위 트랜잭션과 프록시 경계 주의점.

## 이벤트 전달 정책

업무 이벤트와 전송 payload, 필수 처리와 부수 효과, 실패·재처리·순서 정책.

## 검증 항목

ID | 동작 시나리오 | 기대 결과

## 결정 사항

기존 동작·문서의 충돌, 선택한 정합성, 확정·구현 대기·보류 상태를 구분.

## 근거

코드, 정책 문서와 필요한 공식 기술 문서 링크.
```
