# 아키텍처 산출물

현재 구현을 조사한 지도와 구조 전환 결정을 보관하는 내부 산출물 도메인입니다.
개발 기준은 루트 `docs/`와 backend 코드입니다. 문서의 확정 결정은 전환 목표이며 구현 완료를 뜻하지 않습니다.

## 작성 기준

- [템플릿](./templates.md)을 사용합니다.
- 확인일, backend 기준 커밋, 작업 트리 상태를 기록합니다. 커밋만으로 미커밋 변경까지 설명하지 않습니다.
- 현재 코드의 사실, 구조 제안, 미결정을 구분합니다.
- 근거는 메서드가 있는 소스 파일과 현재 개발 문서에 연결합니다.
- 테이블·컬럼·API 엔드포인트 전체 목록을 복제하지 않습니다.
- 공개 개발 기준으로 채택한 규칙은 관련 `docs/backend/`, `docs/decisions/`, `docs/data/`에 선별 반영합니다.
- 운영 절차, 실제 실행 일정과 작업 이력은 `app/secrets/`에서 관리합니다.
- 외부 문서 도구로 자동 동기화하지 않습니다. 이 디렉터리의 Markdown이 산출물 원본입니다.

## 검증

artifacts 저장소에서 실행합니다.

```powershell
python architecture/validate.py
```

검증 범위는 필수 절, 내부 링크, 표의 열 수, 분류 ID 중복, 제안 의존성 그래프의 순환입니다.
로컬 링크는 현재 워크스페이스 배치에서 확인합니다. 코드 근거는 조사 기준 커밋의 GitHub permalink이며, 해당 Git 객체의 파일 존재 여부를 별도로 확인합니다.
코드 근거의 해석과 업무 정합성은 직접 리뷰합니다. 이 검증은 Java 의존성 분석이나 트랜잭션 동작 테스트를 대신하지 않습니다.

공개 개발 문서의 링크와 분류 감사는 루트에서 별도로 실행합니다.

```powershell
python .agents/skills/matchuri-doc-governance/scripts/audit_docs.py --root . --strict
```
